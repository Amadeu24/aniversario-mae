# 🌸 Feliz Aniversário Mãe

Site de homenagem de aniversário com foto, música e QR Code.

## 📁 Arquivos
- `index.html` — página principal
- `foto.jpg` — foto da família
- `musica.mp3` — música especial

## 🚀 Como hospedar no GitHub Pages

1. **Criar repositório no GitHub**
   - Acesse https://github.com/new
   - Nome sugerido: `aniversario-mae`
   - Marque como **Público**
   - Clique em **Create repository**

2. **Fazer upload dos arquivos**
   - Na página do repositório, clique em **Add file → Upload files**
   - Arraste os 3 arquivos: `index.html`, `foto.jpg`, `musica.mp3`
   - Clique em **Commit changes**

3. **Ativar GitHub Pages**
   - Vá em **Settings → Pages**
   - Em *Source*, selecione **Deploy from a branch**
   - Branch: **main** | Pasta: **/ (root)**
   - Clique em **Save**

4. **Acessar o site**
   - Após 1-2 minutos, o link aparecerá:
   - `https://SEU_USUARIO.github.io/aniversario-mae/`

5. **O QR Code**
   - O QR Code é gerado automaticamente com o link do seu site!
   - Pronto para compartilhar 🎉
